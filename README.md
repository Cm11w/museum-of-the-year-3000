Museum of the Year 3000 — the label a museum in the year 3000 puts beside an ordinary object from today: a CAPTCHA checkbox.

> Humans proved they were not machines by ticking the 'I am not a robot' box. The box believed them.

## Run it

```sh
node main.ts
```

This writes the one-line label (98 characters) to `entry.txt` under `$OUTPUT_DIR` (or `$MAKEFUN_OUTPUT_DIR`, default `/output`).
